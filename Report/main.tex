\begin{abstract}
Francais.vn is a mobile-first web platform for Vietnamese learners studying French. The MVP focuses on a clear learning path, lesson-based exercises, progress tracking, quick note-taking, guest trial conversion, and an admin CMS for content operation. This report consolidates the software requirements specification, sprint plan, system design, architectural design, database model, user flow model, and placeholders for implementation and testing evidence.
\end{abstract}
