\subsection{Sprint 3 and Phase 2}

Sprint 3 focuses on Shadowing, Saved Mistakes, Streak, performance, accessibility, SEO, error states, analytics, content production, regression testing, and public launch preparation. Phase 2 includes mock tests, real exam timer, placement test, AI correction, payment, and community features after MVP validation.

\subsection{Critical Path and Risks}

The critical path begins with the database schema and content management model. Admin lesson creation enables the learning path, lesson UI, exercise flow, and progress tracking. Dictation depends on the audio upload pattern established in admin content management. Shadowing depends on the audio and browser media patterns validated in Sprint 2.

Major risks include unresolved technology stack decisions, audio upload complexity, MediaRecorder compatibility on iOS Safari, slow content production, and confusing text comparison rules for dictation.
