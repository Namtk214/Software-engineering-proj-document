\subsection{Critical Path and Risks}

\paragraph{Critical Path (completed phases).}
Phase 1 unblocked everything: the Payload collections, migrations, and seed data had to exist before any real data could flow. Phase 2 (auth) unblocked Phase 3 (progress tracking), because writing LessonProgress requires an authenticated learner identity. Phase 3 grading depends on Phase 1 question blocks being correctly structured.

\paragraph{Critical Path (Phase 4).}
The Vocabulary SRS backend and Notes persistence are independent of each other and can be parallelised. Dictation audio depends on establishing the Media upload pattern already proven in Phase 1. Discussion depends on the Learners collection being stable (Phase 2, done).
