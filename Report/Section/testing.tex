\subsection{Testing Strategy}

\begin{itemize}[leftmargin=*]
  \item Unit testing: compare rules, progress calculation, service-layer business logic, validation helpers.
  \item Integration testing: authentication flow, lesson/exercise submission, note autosave, guest progress merge.
  \item End-to-end testing: register to dashboard to lesson to exercise to progress update; guest to register; note creation; dictation submission.
  \item UI testing: responsive layout at 320px, iPhone SE, iPhone 12, desktop, and keyboard navigation.
  \item Non-functional testing: Lighthouse performance, accessibility contrast, basic security checks, file upload constraints.
\end{itemize}
